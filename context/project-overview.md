# Project Overview

## Product
Master Company Website / Operations Portal.

## Goal
Create a simple, maintainable internal company portal that gives employees and administrators a single entry point for Projects, Finance, HR and Reports while keeping authoritative business data in controlled Google services.

## Primary users
- Ordinary employees
- Project members
- Administrators
- Authorized finance/HR users

## Core journey
Employee opens the Master Google Site → navigates to the permitted area → views permitted information or submits a required Google Form → authoritative data is stored in Google Sheets/Drive → Apps Script performs approved automation → results/notifications are surfaced through the portal or email.

## Core modules
- Projects
- Finance
- HR
- Reports
- MOM
- Notes
- Expense / reimbursement workflows
- Salary administration
- Investment administration

## Authoritative architecture
- Google Sites: portal/presentation/navigation
- Google Sheets: structured operational data
- Google Forms: controlled data-entry workflows
- Google Drive: files and document storage
- Google Apps Script: automation, calculations, notifications and reporting

## Five implementation phases
1. Google Drive structure
2. Master Google Site
3. Google Sheets + Forms
4. Apps Script automation
5. Testing + permissions + handover

## Scope discipline
The project does not require the advanced visual website-builder architecture that was previously attempted. The current objective is to satisfy the business workflow with the agreed Google-native architecture.

## Cost constraint
Target additional software/service spend: ₹0.

Existing Google AI Pro is treated as an existing resource, not a new project purchase.

## Success
The system is successful when the five phases are implemented, the end-to-end workflows work, permissions protect sensitive data, automation is verified, cost/quota gates pass, UAT passes and handover is complete.
