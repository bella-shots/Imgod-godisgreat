# Feature 02 — Master Google Site

## Goal
Create the Master Google Site as the portal and navigation layer.

## Dependency
Feature 01 must be verified.

## Required pages
- HOME
- PROJECTS
- FINANCE
- HR
- REPORTS

## Scope
- Create the Site.
- Configure navigation.
- Link/embed only approved content.
- Keep sensitive source sheets protected.
- Establish administrator editing access.
- Establish employee viewing access according to the permissions model.

## Out of scope
- Sheets schema
- Forms
- Apps Script automation
- Salary calculations
- Reimbursement calculations
- Advanced custom visual-builder functionality

## Verification
- All five pages exist.
- Navigation works.
- Employee access is appropriate.
- Admin editing works.
- Sensitive source data is not broadly exposed.
- Site links point to the approved authoritative resources.

## Done condition
Site structure and access checks pass.
