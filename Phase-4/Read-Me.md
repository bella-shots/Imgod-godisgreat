| MASTER WEBSITE — 2-DAY BUILD PLAN |  |
|---|---|
| Purpose | Build the requested internal company master website for approximately 20 users. |
| Critical implementation strategy | Use Google AI Studio with the user's existing Google AI Pro subscription as the AI-assisted implementation environment. Target ₹0 additional software/service spend. |
| Current architecture | Simple Google-native internal portal using Google Sites, Sheets, Forms, Drive and Apps Script. |
| Employee accounts | Normal Gmail/Google Accounts are the intended employee access model; individual paid Workspace subscriptions are not a prerequisite. |
| Cost target | ₹0 additional software/service spend beyond the user's existing Google AI Pro resource, subject to Google service/account quotas and availability. |
| Phase 4 scope | Apps Script automation only. Automate calculations, notifications, MOM emails, reimbursements, salary carry-forward and reports against the Phase 3 data structures. |
| Phase 4 boundary | Do not redesign the Site, create a new core database schema, or perform final system-wide testing/handover. Those remain outside Phase 4. |
| Sensitive data | Salary, investment, finance and HR source data remain restricted. Automation must not broaden employee access. |
| Visual builder | Advanced visual-builder requirements are intentionally deprioritized; business objective and zero additional cost are the priority. |
| Quota rule | ₹0 does not mean unlimited. Apps Script execution, email, trigger, storage and related quotas must be respected. |
| Phase 4 exit | All approved automation modules work, trigger correctly, handle failures safely, respect permissions and pass the Phase 4 acceptance gate. |
| Current build state | Phase 4 is the Apps Script automation layer. Phase 5 remains final testing, permissions verification and handover. |
