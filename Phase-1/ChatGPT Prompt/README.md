# ChatGPT Prompt

This folder contains the implementation/revision prompts generated from the Phase 1 documentation.

- Each execution cycle gets a new `Prompt-NNN.md`.
- Never overwrite an earlier prompt.
- Prompts must be grounded in the Phase 1 requirements.
- A new prompt is created only when implementation or revision work is required.
- If human assistance is required, the prompt must not pretend that the human action has already occurred.

See `../Instructions.md` for the complete workflow.
