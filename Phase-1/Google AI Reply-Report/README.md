# Google AI Reply-Report

This folder contains the reports produced by Google AI after executing the corresponding ChatGPT prompts.

- Each execution cycle gets a new `Report-NNN.md`.
- Never overwrite an earlier report.
- The report must describe actual work completed and actual tests performed.
- Any human action required must be explicitly identified.
- Incomplete work must not be presented as complete.

See `../Instructions.md` for the complete workflow.
