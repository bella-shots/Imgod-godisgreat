# ChatGPT Feedback — Phase-2

This folder contains ChatGPT's review of each Google AI implementation report.

- Each execution cycle gets a new `Feedback-NNN.md`.
- Never overwrite earlier feedback.
- Feedback must compare the report against this phase's requirements and acceptance criteria.
- If revision is required, create the next prompt in `../ChatGPT Prompt/`.
- If everything passes, record PASS and stop the phase loop.
- If human action is required, record HUMAN ACTION REQUIRED and do not assume it has happened.

See `../Instructions.md` for the complete workflow.
