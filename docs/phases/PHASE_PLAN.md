# Authoritative 5-Phase Plan

## Phase 1 — Google Drive structure

Build the secure Drive foundation.

Required root:

MASTER COMPANY
- Projects
- Finance
- HR
- Templates
- MOM
- Reports

## Phase 2 — Master Google Site

Build the portal navigation:

- HOME
- PROJECTS
- FINANCE
- HR
- REPORTS

## Phase 3 — Google Sheets + Forms

Build operational data structures and controlled submission forms for projects, employees, expenses, reimbursements, salary administration, investments, MOM and reporting.

## Phase 4 — Apps Script automation

Automate:

- MOM emails
- expense calculations
- reimbursement workflows
- salary carry-forward
- reports
- notifications
- audit/error handling

## Phase 5 — Testing + permissions + handover

Complete:

- end-to-end tests
- permission/security tests
- cost and quota verification
- user acceptance testing
- defect closure
- handover/documentation

## Phase Gate Rule

A phase is not considered complete merely because its documentation exists. The actual Google-service implementation and its acceptance tests must pass before the phase is marked complete.
